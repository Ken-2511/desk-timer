# desk-timer

使用 Arduino Nano 制作的桌面计时器，同时用于学习 KiCad 原理图和 PCB 设计。

## 第一版功能

- 固定计时 25 分钟。
- 6 颗 LED 显示剩余进度。
- 两个按钮分别用于开始／暂停、复位计时。
- 计时结束后由无源压电蜂鸣器提示，可通过程序改变音调。
- 通过 Nano 的 USB 接口供电和下载程序。

## 元器件清单

当前采用 **TDK PS1240P02BT 压电式无源蜂鸣器**方案；电阻和两颗电容均采用 1206 贴片封装，其余元件的安装方式见表。

| 元件 | 数量 | 型号／电气规格 | 封装／尺寸与安装方式 | 备注 |
|---|---:|---|---|---|
| Arduino Nano | 1 | 暂按经典款 5V／ATmega328P Nano v3.x | 已焊排针，插装到排母 | 用户已有；具体型号、引脚定义和两排间距待确认 |
| Nano 排母 | 2 | 单排 1×15Pin，间距 2.54mm | 直插；两排中心距暂按 15.24mm | 焊在底板上，用于插拔 Nano |
| 绿色 LED | 6 | 例如 Kingbright WP7113GD，雾面绿色 | 直径 5mm、两脚直插、脚距 2.54mm | 进度指示；每颗单独串联一个限流电阻 |
| LED 限流电阻 | 6 | 680Ω，¼W | 1206 贴片，约 3.2×1.6mm | 按经典款 5V Nano 设计 |
| 轻触按钮 | 2 | Omron B3F-1000，常开瞬时按钮 | 6×6mm、四脚直插、孔位 6.5×4.5mm | 开始／暂停、复位计时；四脚对应两个电气端子 |
| 压电式无源蜂鸣器 | 1 | TDK PS1240P02BT，外部方波驱动 | 直径 12.2mm、高 6.5mm、两脚直插、脚距 5mm | 提示音先按约 4kHz；实际响度待样机确认 |
| 蜂鸣器串联限流电阻 | 1 | 330Ω，¼W | 1206 贴片 | 限制 GPIO 切换时的瞬态电流 |
| 蜂鸣器隔直电容 | 1 | 1µF，非极性，耐压 ≥16V | X7R 陶瓷、1206 贴片 | 与 330Ω 串联；采购时匹配容量、耐压和封装 |
| 蜂鸣器泄放电阻 | 1 | 100kΩ，¼W | 1206 贴片 | 并联在蜂鸣器两端 |
| 电源去耦电容 | 1 | 100nF，非极性，耐压 ≥16V | X7R 陶瓷、1206 贴片 | 跨接 5V 与 GND；采购时匹配容量、耐压和封装 |
| USB 数据线 | 1 | 与现有 Nano 的 USB 接口匹配 | 板外配件 | 需要支持数据传输，供电和下载程序共用 |

该方案不再使用此前电磁蜂鸣器方案中的 BC337、220Ω 基极电阻、10kΩ 基极下拉电阻和 1N4007 续流二极管。

## 蜂鸣器驱动接法

```text
Nano GPIO ── 330Ω ── 1µF ──┬── PS1240P02BT ── GND
                           └── 100kΩ ───────── GND
```

这是本项目拟采用的 GPIO 驱动方案，并非照搬厂商参考电路：串联电容隔直，100kΩ 电阻提供电荷泄放通路，330Ω 电阻限制切换瞬间的电流；按 5V 电平跳变估算约为 15mA。

程序使用 `tone()` 输出约 4kHz 方波，停止提示时结束方波输出；实际响度、波形及 GPIO 负载在样机阶段确认。

## LED 与 GPIO 对应

PCB 上 D1–D6 从左到右排列，分别经 R1–R6 连接 Nano 的 D7、D6、D5、D4、D3、D2；这一顺序用于减少布线交叉。
固件中从左到右的 LED 引脚数组应为 `{7, 6, 5, 4, 3, 2}`。

## PCB 布线配置

- 80 × 50 mm 双层板；保留当前元件布局。
- 默认信号线宽 0.30 mm；5V 和 GND 的 Power 网络类线宽 0.50 mm；铜间距 0.25 mm。
- 过孔直径 0.80 mm、钻孔 0.40 mm；铜到板边至少 0.50 mm。
- 主要连线在顶层；底层两段短跳线，其余以连续 GND 铺铜为主；共 5 个过孔。
- 底层 GND 区采用热焊盘连接，间隙及连接桥宽均为 0.30 mm，并移除孤立铜岛。
- 本次填充铜区后 DRC：0 违规、0 未连接；焊盘网络与原理图一致。
